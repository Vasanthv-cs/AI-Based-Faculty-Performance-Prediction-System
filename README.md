# 🎓 AI-Based Faculty Performance Prediction System

🚀 An **AI-powered academic analytics platform** that digitizes and automates the faculty appraisal process.
This system transforms traditional paper-based evaluation into a **data-driven, real-time performance monitoring and prediction platform**.

Faculty members can log their academic contributions, upload supporting documents, and instantly view their appraisal score based on a **250-point institutional evaluation framework**.

The system uses a **modern serverless architecture** combining a React frontend with a Supabase backend to ensure scalability, security, and fast performance.

---

# ✨ Features

## 📊 Faculty Performance Tracking

Faculty can record their academic activities such as:

* 📚 Teaching performance
* 📄 Research publications
* 🎤 Conferences & workshops
* 🎓 FDP programs and certifications
* 🏫 Institutional contributions

Each activity contributes to a **real-time appraisal score**.

---

## 🤖 AI-Based Performance Prediction

The system analyzes faculty contributions and provides **smart insights** to predict future performance.

Examples:

* Suggest research publications to improve score
* Recommend FDP programs for professional development
* Predict possible appraisal grade based on current progress

---

## 🧮 Automated Scoring System

The system follows a **250-point academic evaluation model**.

| Category                      | Maximum Points |
| ----------------------------- | -------------- |
| 📘 Teaching & Learning        | 50             |
| 🔬 Research Activities        | 100            |
| 🌐 Networking & Contributions | 100            |

### 🏆 Final Performance Grade

| Score Range | Grade               |
| ----------- | ------------------- |
| 200 – 250   | ⭐ Excellent         |
| 150 – 199   | 👍 Very Good        |
| 100 – 149   | 🙂 Good             |
| 0 – 99      | ⚠ Needs Improvement |

## 🔐 Role-Based Access Control

The platform supports three main roles:

### 👨‍🏫 Faculty

* Add academic activities

* Monitor progress dashboard

### 🧑‍💼 HOD (Head of Department)

* Monitor department faculty performance
* Verify uploaded documents
* Analyze departmental productivity

### 🏛 Admin

* Manage institutional users
* Monitor global faculty analytics
* Export institutional reports
